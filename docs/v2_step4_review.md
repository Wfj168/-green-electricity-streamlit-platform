# 融合版 V2 第四步复盘与检验

## 实现结果

- 建立 PostgreSQL V2 初始化脚本和独立 Compose 数据库服务。
- 建立 25 个核心业务表，覆盖 11 个数据域。
- 金额字段固定 `CNY`，页面统一显示人民币。
- 直连送端注入、受端送达、线路损耗分列保存。
- 储能按光伏、直连、电网和不可核验来源分账。
- 参数值关联来源证据、来源等级和不确定性区间。
- 模型任务关联模型版本、参数版本、输入快照和输入校验和。
- 时序表建立园区时间索引和 BRIN 时间索引。

## 复盘

- 当前 Streamlit 的 SQLite 数据库保持不变，V2 PostgreSQL 独立建设，降低迁移风险。
- 首期采用原生 PostgreSQL 时序索引，数据量增长后再迁移 TimescaleDB 超表，避免早期增加非必要依赖。
- 当前开发电脑未安装 Docker，无法在本机启动 PostgreSQL 容器；已完成静态 SQL 合约验证，容器启动、外键和迁移幂等性将在部署环境复验。

## 检验结果

- 数据域覆盖测试：通过。
- 人民币与参数证据约束测试：通过。
- 直连注入、送达和损耗字段测试：通过。
- 储能来源分账字段测试：通过。
- 时序索引测试：通过。
- 合计：5/5 通过。

# 第一阶段平台页面与中文化改造

## 1. 当前主导航

第一阶段保留四个主页面：

1. 平台概览：农业园区边界、四类负荷、推荐容量、三策略结论、年度能量流和重点风险。
2. 参数配置与运行：参数来源等级、当前值、上下限、设置方法、四类负荷明确值、正式数据模板和一致性复核。
3. 运行分析：月度农业生产日历、能量流、逐时供能、储能来源分账、成本碳排与压力测试。
4. 场景与决策：只比较现状、绿电直连过渡和零碳协同三种策略，形成分阶段建议。

成果导出全部作为相关页面中的下载按钮，不设置独立“结果导出”页面。15分钟数据与预测工具嵌入参数页并默认收起，不单独占据主导航。“工程架构”不再作为业务页面展示。

## 2. 原V17兼容功能

原县域综合能源S0—S8、热电联产、绿氢、电转其他能源和多能典型日功能仍保留在代码中，但从农业专项主流程移出。用户只有主动勾选“显示原V17兼容功能”后才会看到，避免第一阶段演示被无关场景分散。

快速电力滚动调度在模型选择中标记为“兼容”，第一阶段默认进入“V17农业零碳园区规划”。

## 3. 页面中文口径

- 主页面标题、图例、指标、单位、按钮和判定文字使用中文。
- 金额只使用人民币元或万元，不使用欧元或外币换算。
- 能量、功率、碳排分别统一为兆瓦时、兆瓦和吨二氧化碳。
- 算法内部英文变量只保留在代码和下载成果中，不作为主页面指标名。
- Streamlit框架自身的部署菜单属于托管平台界面，不是业务系统文案。

## 4. 参数来源展示

参数页显示71项注册参数，当前包含67项E级演示参数、2项待赋值参数和69项正式交付缺口。每项参数都显示来源等级、来源依据和设置方法。

这意味着平台已经能够回答“数字从哪里来、按什么方法设置”，但因为真实园区资料尚未接入，仍不能回答“该数字是否已经代表实际园区”。页面用黄色提示持续披露该边界。

## 5. 项目与任务说明

项目中心不是未开发页面。后台地址有效时，它会自动出现在导航中，用于保存版本化场景、提交后台任务和读取历史成果；单机演示或后台配置无效时自动隐藏。该设计避免用户进入一个无法工作的空页面。

## 6. 检验结果

- 四个主页面端到端测试通过。
- 原V17配置和S0—S8对比在手动展开后仍可运行，兼容路径没有被删除。
- 1600×1050浏览器实渲染检查覆盖概览、参数、分析和决策四页。
- 当前现状审计17项问题中16项已完成整改，唯一未关闭项为“当前农业负荷仍是合成数据”。

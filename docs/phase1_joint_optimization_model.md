# 第一阶段农业园区成本—碳排—绿电匹配联合优化模型

## 1. 实现结果

V17农业专项已经从“页面固定容量加年度后处理”升级为全年连续时序联合优化。模型在同一组约束中决定本地光伏容量、外部绿电直连合同容量、储能功率、储能容量、公共电网最大需量和逐时运行计划。

正式零碳方案采用2025年连续8760小时计算。1、2、3、4或6小时聚合只作为快速试算入口，不能替代小时级零碳结论。15分钟日前与滚动调度将在后续运行层复用同一套物理变量和约束。

## 2. 优化目标

目标函数最小化年总成本，所有金额均为人民币：

`年总成本 = 光伏年化投资运维 + 储能年化投资运维 + 直连固定工程年化 + 直连绿电购电 + 公共电网电量费 + 最大需量费 + 碳成本 + 储能衰减 + 弃电惩罚 - 外送收益`

其中年化系数由20年规划期和5%折现率计算。绿电直连固定工程费会造成“建设”和“不建设”之间的不连续；程序分别求解两个连续线性规划，再比较包含固定费后的总成本，避免把固定工程费错误摊成任意小容量。

## 3. 逐时物理约束

每个时段同时满足：

- 本地光伏出力分配到负荷、储能、外送和弃光。
- 直连绿电扣除3.5%线路损耗后分配到负荷、储能、外送和弃电。
- 园区负荷由光伏直供、直连直供、两类绿电来源储能放电和普通电网购电共同满足。
- 储能分别维护“光伏来源”和“直连来源”荷电状态，不允许普通电网电量混入物理绿电。
- 储能荷电状态逐时连续、年初年末循环闭合，并受功率、额定容量、荷电范围、效率、自放电和等效循环约束。
- 直连与公共电网共同受4.50兆瓦园区进口边界约束，外送受0.50兆瓦边界约束。
- 物理绿电目标通过限制普通电网年购电量实现；100%目标等价于普通电网逐时供能总量为零。

当前价格口径下，购电价严格高于同期净外送价，储能衰减成本严格高于弃电惩罚。因此同一时段购售电和充放电是严格劣解；程序在求解前检查这两个条件，并在求解后统计冲突时段。若正式价格破坏条件，系统会拒绝求解并要求启用整数互斥约束，而不会静默产生套利结果。

## 4. 农业生产任务约束

灌溉、粮食加工和仓储冷链分别保留不可移动部分与可转移部分。每类负荷每天必须完成与基线相同的用电任务，优化只能在当天设备功率上限内移动可转移电量，不能通过删除灌溉、减少加工或牺牲冷链温控来降低成本。公共辅助负荷当前全部按给定曲线执行。

本阶段的任务约束证明“日任务电量完成”，尚不能代替正式项目中的灌溉水量、加工产量和库温实测约束。正式数据模板已经预留任务量、最早开始、最晚结束和设备功率字段。

## 5. 三策略同口径结果

| 指标 | 现状基准 | 绿电直连演示方案 | 零碳协同优化 |
|---|---:|---:|---:|
| 本地光伏/兆瓦 | 0.000 | 1.500 | 4.000 |
| 绿电直连/兆瓦 | 0.000 | 1.000 | 2.608 |
| 储能功率/兆瓦 | 0.000 | 0.800 | 1.965 |
| 储能容量/兆瓦时 | 0.000 | 2.000 | 7.858 |
| 普通电网购电/兆瓦时 | 8902.36 | 2256.27 | 0.00 |
| 物理绿电匹配率 | 0.00% | 74.65% | 100.00% |
| 运营碳排放/吨 | 4896.30 | 1241.06 | 0.00 |
| 年总成本/万元 | 679.88 | 660.95 | 757.11 |
| 平均供能成本/元每兆瓦时 | 763.70 | 742.44 | 850.46 |

零碳协同方案相对现状基准的年成本增加约77.24万元，约11.36%；它需要4.00兆瓦光伏、2.608兆瓦直连和1.965兆瓦/7.858兆瓦时储能。该方案还出现约5833.64兆瓦时弃电和3884.87兆瓦时外送，说明追求每小时绝对零普通电网供能会导致明显过配，不应包装成无代价的理想方案。

绿电直连演示方案没有达到零碳，但在当前演示价格下同时将年成本降低约18.93万元、将运营排放降低74.65%。这使它成为进入正式数据阶段后优先复核的过渡方案。

## 6. 复盘与判定边界

- 8760小时零碳方案的最大母线平衡误差小于`3×10^-15`兆瓦。
- 三类农业生产任务的最大日能量误差小于`1×10^-8`兆瓦时。
- 同时充放电时段为0，同时购售电时段为0。
- 全部金额使用人民币，没有欧元换算。
- 当前负荷、造价、价格、碳因子和设备边界仍属于E级演示参数，所以页面只能显示“计算排放为零，演示参数待正式核验”，不能显示正式项目已经获得零碳认证。

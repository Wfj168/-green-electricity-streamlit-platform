# 第一阶段农业零碳结果图设计与复盘

## 1. 页面叙事顺序

运行分析页不再以雷达图或多个孤立百分比作为主结论，而是按决策问题排序：

1. 农业生产日历与四类负荷：解释春灌、夏季冷链和秋收加工如何形成月电量与峰值。
2. 三策略成本与碳排：同时展示现状、绿电直连和零碳协同方案的人民币年成本与绝对碳排放。
3. 年度能量流向：展示光伏、直连绿电、普通电网、储能、四类负荷、外送、弃电和损耗的兆瓦时流向。
4. 月度供需闭环：验证不同农时月份由哪些电源满足，不用典型日替代全年结果。
5. 零碳绿电去向：把负荷消纳、外送、弃电和线路损耗并列，直接披露过配代价。
6. 关键农时逐时调度：可选择春灌、夏季冷链、秋收加工和冬季低光伏四个日期查看逐时供能与弃电。
7. 储能来源分账：分别显示光伏充电、直连充电、放电以及两类绿电存量。
8. 三策略明细对账与下载：保留绝对量、容量、成本和判定文字。

## 2. 图表口径

- 月用电量和能流统一使用兆瓦时，功率统一使用兆瓦。
- 成本统一使用万元或元每兆瓦时，底层金额均为人民币元。
- 碳排统一使用吨二氧化碳，不再把不同含义的百分比裁剪到同一雷达图。
- 所有农业图读取全年连续时序和第6步联合优化结果，不读取原V17典型日拼接结果。
- 页面结论同时显示“模型计算排放为零”和“演示参数待正式核验”，不把演示计算包装成正式零碳认证。

## 3. 性能与交付

8760小时优化结果由导出脚本生成三个轻量文件：三策略对比表、零碳汇总表和压缩逐时调度表。页面冷启动直接读取已核验结果，避免现场演示时重新等待求解。参数变化后的正式运行仍可调用同一优化服务重新生成这些成果。

## 4. 检验结果

- 7组农业图表均通过结构测试，确认图层、绝对能量值和来源分账字段存在。
- Streamlit页面端到端测试通过，所有导航页面无未捕获异常。
- 1600×1050浏览器实渲染检查通过，标题、五项核心指标、首屏两张主图和能量流图均正常显示。
- 原V17综合能源结果暂以“兼容保留”区存在，后续页面简化步骤将进一步降低其优先级。

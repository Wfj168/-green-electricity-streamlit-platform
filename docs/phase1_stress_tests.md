# 第一阶段农业零碳方案合理性与压力测试

## 1. 检验方法

压力测试固定第6步推荐容量，不允许模型在压力发生后自动扩建光伏、直连或储能。这样检验的是“推荐方案本身能否承受变化”，不是重新规划后能否找到另一个方案。

压力筛查采用全年连续3小时块，保留四季、春灌和秋收日历；正式零碳基准仍以8760小时精算为准。每个压力场景继续检查母线平衡、农业日任务、储能来源、充放电冲突和购售电冲突。

固定容量为：光伏4.000兆瓦、绿电直连2.608兆瓦、储能1.965兆瓦/7.858兆瓦时。

## 3. 复盘结论

当前推荐容量不是稳健零碳方案。六类压力中，低光伏、秋收集中加工和绿电直连受限三类会重新产生普通电网购电和运营排放。后续不能只给一个容量点，应增加以下一种或多种设计：

- 为光伏、直连或储能增加经过经济比较的可靠性裕度。
- 建立可核验的备用绿电合同，但合同覆盖率必须与物理匹配率分开显示。
- 为集中加工任务设置可执行的跨日生产窗口、产量和截止时间。
- 对直连中断建立备用供能与恢复策略。

绿电直连受限时年成本反而下降14.43%，不是经济性改善，而是当前演示合同按实际注入电量结算，少供绿电减少了购电支出，同时失去了零碳目标。页面必须同时展示成本和排放，禁止只根据成本下降推荐该压力结果。

春灌增长未造成缺口，是因为当前时序中春季仍有可利用绿电余量，且灌溉任务允许日内移动；这不代表真实园区一定具备该裕度。正式项目需用水量、泵组功率、供水时限和渠系约束替换演示设置。

## 4. 检验结果

- 基准和全部可行压力场景的最大母线误差小于`3×10^-15`兆瓦。
- 三类生产任务最大日能量误差小于`3×10^-15`兆瓦时。
- 固定容量测试验证通过，模型未在压力场景中静默扩容。
- 超过农业园区容量边界的固定资产输入会被拒绝。
- 机器可读结果位于`data/demo/phase1_stress_test_results.csv`。

## 3. 当前模型边界

当前Streamlit业务链路使用的是StoreMore风格电力侧滚动线性规划，覆盖风电、光伏、燃气发电、购售电、储能、弃电和缺电。仓库同时保留V17县域—园区多能系统模型及S0—S8结果，但它与当前实时业务页面尚未统一为同一个工程服务。

平台可用于方案筛选和决策辅助，不能替代真实配电网潮流、继电保护、设备控制、并网审查或施工设计。

## 4. 已识别的工程缺口

1. Streamlit页面直接调用求解函数，界面、业务和算法尚未完全解耦。
2. 结果只保存在`session_state`，没有数据库、项目、场景版本和历史任务。
3. 没有登录、权限、用户隔离和审计日志。
4. 没有后台任务队列、超时、取消、重试和并发控制。
5. `restrict_investments`已进入输入和导出，但当前容量规划尚未实际执行该限制。
6. 部分成本字段仍标注为`proxy`，正式交付前需统一币种、口径、年化方法和单位。
7. CSV校验主要集中在列识别、缺失值和边界裁剪，尚缺完整数据契约和逐行错误报告。
8. 异常处理仍存在宽泛捕获，尚未形成结构化错误码。
9. 尚无备份恢复、监控告警、健康检查和正式发布回滚机制。
10. V17模型与实时StoreMore引擎的职责、切换方式和结果口径尚需统一。

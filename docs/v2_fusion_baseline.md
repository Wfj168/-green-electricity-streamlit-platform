# 融合版 V2 页面、数据与验收基线

## 1. 基线结论

- 视觉和页面基准：`https://ltgh.xmnh2026.cloud:38999` 当前公开可观察版本。
- 业务和算法基准：本仓库现有零碳农业园区模型、8760 小时/15 分钟农业负荷、绿电直连、储能溯源、联合优化、策略对比与压力测试。
- 迁移原则：保留新平台的登录页、深色主题、顶部栏、园区切换、分组侧栏、面包屑、卡片、图表和全部业务路由；不迁移固定指标、模拟接口、前端假认证和通用空壳数据。
- 运行原则：所有展示值必须来自数据接口、参数快照或模型任务；未接入的数据统一显示“尚未接入”，演示数据必须显式标注。
- 切换原则：融合版在 `frontend/` 独立建设，当前 Streamlit 应用在验收通过前保持不变。

## 4. 页面数据证据规则

每张指标卡、图表和表格必须随响应提供以下元数据：

1. `park_id`：园区标识。
2. `as_of`：数据时点。
3. `data_status`：实时、延迟、演示、估算或未接入。
4. `source_ids`：测点、文件、合同或上游系统标识。
5. `quality_code`：完整性、及时性、合理性和平衡性状态。
6. `run_id`：如为模型结果，必须包含任务标识。
7. `model_version`：模型与算法版本。
8. `parameter_version`：参数快照版本。
9. `currency`：金额统一为 `CNY`，页面显示人民币。

## 5. 绿电直连融合口径

### 5.1 物理口径

- 分开记录送端注入、受端送达、线路损耗、限发和中断。
- 园区母线逐时满足：本地光伏 + 直连送达 + 电网购电 + 储能放电 = 农业负荷 + 储能充电 + 上网 + 弃电 + 其他损耗。
- 储能按光伏、直连、电网三类来源分账，放电绿电属性按来源追踪，禁止将电网充电重复认定为绿电。

### 5.2 合同口径

- 合同容量、合同曲线、最低消纳、线路可用率、偏差考核、输配与辅助服务费用、容量费用和结算周期进入同一参数快照。
- 物理绿电、绿证和其他环境权益分开展示，防止重复抵扣。

### 5.3 收益口径

统一比较纯电网、光伏、直连、直连+储能、直连+储能+农业柔性五类方案；收益必须相对同一基线计算，并至少拆分为电能量、需量、偏差、储能衰减、弃电、碳、生产和可靠性八个分项。

## 6. 验收门槛

- 路由清单测试：78/78。
- 页面状态测试：六类状态均可复现，不允许无限加载。
- 数据口径测试：所有金额为人民币；演示数据显式标注；无来源数字视为不合格。
- 模型回归测试：迁移前后同一输入的关键结果一致，逐时能量平衡通过。
- 安全测试：错误密码不能登录，越权返回 403，会话过期返回 401，生产环境不发布源码映射。
- 性能测试：生产首屏目标不高于 3 秒；缓存后的页面切换目标不高于 1 秒。
- 视觉测试：三档分辨率逐页截图，无严重遮挡、溢出和错位。

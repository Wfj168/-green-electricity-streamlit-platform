# 0.8.0 发布验收清单

## 1. 版本与范围

- [ ] `VERSION`与`src/version.py`均为 0.8.0。
- [ ] 发布分支由最新`main`创建，差异只包含本次 V17 项目级升级。
- [ ] 变更记录、交接手册、演示讲稿和部署说明相互一致。

## 2. 页面验收

- [ ] V17 导航只有“平台概览、参数配置与运行、运行分析、场景与决策”，连接后台时增加“项目中心”。
- [ ] 快速模式导航只有“平台概览、参数配置与运行、运行分析、绿电决策”。
- [ ] 平台没有“工程架构”和单独“结果导出”业务页。
- [ ] “参数配置与运行”包含“模型参数与运行”和“数据校验与预测”。
- [ ] V17“运行分析”包含综合看板、多能运行、经济性、低碳分析、可靠性与约束、数据明细。
- [ ] 单场景和场景比较成果均通过当前页面按钮下载。
- [ ] 业务金额只出现人民币，不出现欧元。
- [ ] 主要页面单位为中文；英文只用于必要的数据字段、文件格式或工程标识。

## 3. V17 模型验收

- [ ] S0、S4、S8 均求解成功，黄金回归通过。
- [ ] 非 S0 碳约束场景记录 S0 基准、年度目标、当前排放和目标余量。
- [ ] 页面碳市场价格进入目标函数并与碳成本分项一致。
- [ ] 电、热、冷平衡误差在容差内，成本和排放来源对账通过。
- [ ] 工业园绿电覆盖率不超过 100%。
- [ ] 场景比较识别重复核心结果，不将“约束未起作用”解释为额外收益。
- [ ] 负平均减排成本带有“筛查结果、非收益承诺”说明。
- [ ] 可信度审计没有“需核查”硬错误；所有“提示”均在交付材料披露。

## 4. 数据与合理性

- [ ] 合成特征数据被明确标记，不冒充实测数据。
- [ ] 六类典型日权重合计 365 天。
- [ ] 默认购售电价、燃气价、碳价和设备造价均为人民币口径。
- [ ] 正式客户交付前已替换实测负荷、合同价格、设备报价和属地碳因子。
- [ ] 至少完成一个全年 8760 小时或极端工况复核。

## 5. 项目与数据库

- [ ] 无后台地址时项目中心隐藏，平台不请求`127.0.0.1`云端本机地址。
- [ ] 连接后台后可创建项目、保存场景版本、提交任务、查看结果和下载成果。
- [ ] 幂等键重试不生成重复任务。
- [ ] 任务租约、心跳、超时恢复、最大重试和旧执行器写保护测试通过。
- [ ] 数据库结果记录保存成果地址和 SHA-256 校验值。

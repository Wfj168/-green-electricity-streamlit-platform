# 融合版 V2 第九步复盘与检验

## 实现结果

- 新增账号密码登录接口，密码使用 PBKDF2-SHA256 加盐哈希，不存储或返回明文密码。
- 登录成功后签发有时效的访问令牌，前端保存会话并在接口请求中携带令牌。
- 支持系统管理员、规划与调度工程师、运行值班员、只读用户和审计用户五类角色。
- 服务端继续对项目写入、任务创建、审计查询和系统状态实施角色校验。
- 前端可按部署变量要求强制登录，并对无权角色隐藏系统管理菜单、禁用结果导出。
- 11 个系统管理页面全部接入实时系统状态，覆盖组织、账号、角色、模型、接口、告警、单位、任务、组件、备份和审计。
- 系统状态不返回密码哈希、密钥、数据库密码或完整连接串。
- 复用现有持久任务队列、工作进程租约、心跳、重试、取消和过期任务恢复机制。
- 复用并呈现现有校验备份、恢复前回滚备份和恢复演练能力。

## 复盘

- 当前公开演示构建默认不强制登录；生产部署必须同时启用后端令牌模式和前端强制登录变量。
- 融合版 PostgreSQL 表结构已交付，但当前任务服务仍使用 SQLite；系统监控明确显示“待部署配置”，不冒充已经完成数据库迁移。
- 工作进程当前由部署环境单独启动，系统页只能显示配置与任务状态；生产环境还需接入容器/主机级进程监控。
- 公开演示没有配置正式账号，因此用户管理显示 0 个配置账号，这是正确状态。

## 检验结果

- 密码哈希、错误密码、正确登录、当前用户、令牌角色和敏感信息过滤：通过。
- 原有管理员、工程师和只读用户服务端权限回归：通过。
- 任务持久化与状态机、备份校验和恢复保护：15/15 通过。
- 前端类型检查与 4 项组件测试：通过。
- 前端生产构建：通过。
- 系统管理 11/11 页面浏览器联调通过，无接口错误、无占位提示、无控制台错误。

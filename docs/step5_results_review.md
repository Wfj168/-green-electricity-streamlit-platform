# 步骤5复盘：多能流结果与场景比较

## 结论

本阶段门禁通过。V17结果已从原始表格升级为按典型日展示的电、热、冷和储能图表；综合指标按业务主题分组；S0—S8对比由页面触发九次真实模型求解，不读取静态演示数字。

## 多能流结果

- 电力：光伏、风电、热电联产、电网购电和储能放电堆叠展示，同时绘制包含热泵、电制冷、电解槽、储能充电和外送的电力总需求。
- 热力：热电联产、热泵、燃气锅炉、绿氢和蓄热放热共同构成供热侧，并与热负荷和蓄热充热需求比较。
- 冷量：电制冷出力与冷负荷对照。
- 储能：电储能SOC和蓄热SOC同图展示。
- 典型日：按`day_id`选择，显示代表日名称与年度权重，避免把加权典型日误解为连续全年时序。

## 指标分组

真实`metrics`表按关键词映射为能源、经济、环境、可靠性、园区与P2X五组，同时保留“全部”页和执行元数据，不修改模型原始指标名称与单位。

## S0—S8比较算法

1. 为每个选中场景生成`integrated-planning-v1`请求、统一分辨率和随机种子。
2. 逐场景调用`UnifiedModelService`，记录模型版本、参数指纹、耗时和原始指标。
3. 以本次实际S0结果作为基准，计算年度减排量、减排比例、成本变化和平均减排成本。
4. 生成成本—碳排双轴图和成本—碳排权衡前沿。
5. 对比ZIP包含汇总CSV、清单JSON和每个场景的原始结果ZIP，任何汇总指标均可回溯。

## 绿电直连服务

# 融合版 V2 绿电直连与收益分析方法

## 1. 分析对象

统一比较五类全年时序方案：

1. G0 纯公共电网基准。
2. G1 园区光伏。
3. G2 绿电直连。
4. G3 绿电直连加储能。
5. G4 本地光伏、绿电直连、储能和农业柔性负荷联合优化。

五类方案使用相同年度、相同农业任务电量、相同分时电价和相同电网排放因子。结果不跨口径比较。

## 2. 物理计算

每个时段满足：

`本地光伏 + 直连受端送达 + 电网购电 + 储能放电 = 农业负荷 + 储能充电 + 上网 + 弃电`

直连线路满足：

`送端注入 = 受端送达 + 线路损耗`

储能按光伏、直连、电网和不可核验四类来源分账。当前零碳优化器仅允许经核验的本地光伏和直连绿电进入储能，因此不会把公共电网充电错误认定为绿电。

## 3. 合同结算

绿电直连成本除电源侧电量成本外，增加以下独立分项：

- 输配费用。
- 辅助服务费用。
- 通道容量年费。
- 最低消纳不足费用。
- 超限偏差考核。
- 直连固定工程年化投资与运维。

当前没有正式合同计划曲线，因此演示阶段以模型可用曲线作为计划曲线，偏差费用为零并明确标记，不能据此宣称实际项目没有偏差风险。

## 4. 经济性

年总成本包括：

`年化投资运维 + 电网电量费 + 电网需量费 + 直连电量与合同费用 + 储能衰减 + 弃电成本 + 碳成本 - 上网收益`

经济指标包括：

- 相对基准年节省和节省率。
- 初始投资。
- 净现值。
- 内部收益率。
- 静态回收期。

净现值使用参数台账中的规划周期和折现率。现金流将初始投资与年度运行现金成本分开，避免把年化投资重复扣除。

## 5. 碳与绿电

- 碳边界：园区运行期购入普通电产生的范围二排放。
- 物理绿电：本地光伏、直连送达以及可追溯的绿色来源储能放电。
- 绿证和其他权益不与物理绿电合并，当前演示未使用绿证抵扣。
- 减排量始终相对 G0 基准计算。

## 6. 可靠性

系统自动寻找 G0 公共电网需求最大的连续窗口，并模拟该窗口公共电网不可用。各方案的缺供量采用其原调度中的电网剩余需求计算，输出：

- 停电窗口缺供电量。
- 相对基准避免缺供电量。
- 停电损失避免金额。
- 停电窗口生产供能率。

停电损失价值当前为 E 级演示参数，正式项目必须按灌溉、加工、烘干和冷链分别调查。

## 7. 收益归因

使用顺序增量瀑布法：

`公共电网基准 → 加入本地光伏 → 加入绿电直连 → 加入储能 → 加入农业柔性联合调度`

每一环节贡献为加入该环节前后的年总成本差。各环节贡献之和严格等于 G0 与 G4 的净成本差。该方法具有顺序依赖，页面必须显示归因顺序，不将其解释为统计因果。

## 8. 防止过度理想化

- 允许结果显示负收益、成本增加和无法回收，不隐藏不利结果。
- 不具备概率分布时不展示 P10、P50、P90。
- 演示数据、估算数据和正式数据分开标识。
- 零碳结论同时要求排放容差和功率平衡通过。
- 正式参数未核验时，只能表述“计算上实现零碳”，不能表述“项目已实现零碳”。

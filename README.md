# 基于绿电直连的零碳农业园区优化调度平台

当前版本：`1.0.0`（第一阶段）

这是一个面向农业园区的项目级能源规划与优化调度平台。第一阶段围绕“一个园区、四类负荷、三种策略、六类压力测试”，把灌溉、加工、仓储冷链和公共辅助负荷，与本地光伏、外部绿电直连、储能和公共电网放进同一套逐时能量平衡和容量—运行联合优化模型。所有金额统一使用人民币，主要业务界面以中文呈现。

## 当前能力

- 2025年8760小时和35040个15分钟点的四类农业负荷、农时、气象、光伏和价格演示基准。
- 71项参数台账、A至E来源分级、正式数据模板和缺口审计；演示数据明确标记为合成，不作为项目收益承诺。
- 光伏、直连绿电、普通电网、储能、外送、弃电、线路和储能损耗的逐时物理能量流与严格守恒校验。
- 储能按光伏和直连来源分账，只有可追溯的绿电存量才继续计为物理绿电。
- 全年容量—运行联合线性优化，同时选择光伏、直连、储能、最大需量和逐时调度，并约束农业每日任务守恒。
- 现状基准、绿电直连过渡、零碳协同优化三种策略，以及低光伏、负荷增长、直连受限、成本波动和电网限电六类压力测试。
- 农业生产日历、成本—碳排策略、年度桑基能量流、月度平衡、典型农业日、储能来源和压力测试图。
- 原县域V17、S0至S8、多能典型日和数据预测保留为手动展开的兼容功能。
- 结果下载设置在分析和场景页面，不再占用单独导航页面。
- 可选“项目中心”保存项目、场景版本、模型版本、后台任务、结果摘要、成果校验值和审计日志。
- 单节点部署提供前端、接口服务、任务执行器、数据库、成果目录、令牌认证、健康检查、备份和恢复。

## 页面结构

农业V17主流程包含“平台概览”“参数配置与运行”“运行分析”“场景与决策”；连接后台后增加“项目中心”。快速调度作为兼容模式保留。平台不再设置“工程架构”和“结果导出”业务页面，数据质量与预测收进参数页兼容区。

## 本地演示

```bash
pip install -r requirements.txt
streamlit run app.py
```

此方式无需后台数据库，适合单人演示。项目版本、后台任务和历史结果需要启动接口服务与任务执行器：

```bash
uvicorn api:app --host 0.0.0.0 --port 8000
python worker.py --poll-seconds 2
```

前端设置`PLATFORM_API_URL=http://127.0.0.1:8000`后，“项目中心”会自动出现。当前数据库为 SQLite，适合单服务器试点；多实例生产部署应将仓储适配为 PostgreSQL，并把成果文件迁移到对象存储。

## 质量检查

```bash
pip install -r requirements-dev.txt
python -m compileall -q app.py src tests
ruff check .
python scripts/deployment_preflight.py --profile all
pytest
```

自动化质量门还会构建部署镜像。V17 的 S0、S4、S8 和默认快速调度均有黄金回归基线。

## 云端演示说明

Streamlit Community Cloud 只运行前端时，项目中心不会出现，其他 V17 配置、求解、分析、场景比较和成果下载仍可使用。不要把云端前端的后台地址配置为`127.0.0.1:8000`；若需要项目中心，应配置一个浏览器可访问的独立接口地址。

## 使用边界

本平台用于园区综合能源方案筛选、低碳指标评估和绿电方案比较。正式决策前必须以项目实测负荷、当地合同电价、设备报价、碳排放因子和工程边界重新标定。平台不替代配电网潮流、短路电流、继电保护、接入审查、施工图或财务尽调。

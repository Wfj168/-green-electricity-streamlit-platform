# 园区低碳规划与绿电直连优化平台

当前版本：`0.8.0`

这是一个以 V17 综合能源规划为核心、兼顾快速电力调度的项目级优化平台。平台围绕“配置—求解—分析—比较—交付”形成闭环，所有金额统一使用人民币，主要业务界面以中文呈现。

## 当前能力

- V17 联合规划电、热、冷、气、光伏、风电、热电联产、热泵、电制冷、燃气锅炉、电储能、蓄热、柔性负荷、绿电直连和电转其他能源。
- S0—S8 场景由同一模型真实求解；碳约束场景先计算 S0 基准，再形成年度目标并进入优化约束。
- 驾驶舱概览与运行分析包含年度能流桑基图、目标雷达、容量边界、全年热力图、持续时间曲线、典型日多能流、成本瀑布、分时碳强度、可靠性约束和模型可信度审计。
- 场景决策支持四种偏好的多准则相对排序、决策热力矩阵、平行坐标和边际成本—减排分析；原始场景结果始终保留。
- 关键造价、电价、燃气价和碳价采用人民币口径；示例数据明确标记为合成特征数据，不作为项目收益承诺。
- 数据质量与预测合并在“参数配置与运行”中，支持 15 分钟数据校验、透明基线预测和继承储能状态的日内请求。
- 结果下载设置在分析和场景页面，不再占用单独导航页面。
- 可选“项目中心”保存项目、场景版本、模型版本、后台任务、结果摘要、成果校验值和审计日志。
- 单节点部署提供前端、接口服务、任务执行器、数据库、成果目录、令牌认证、健康检查、备份和恢复。

## 页面结构

V17 模式包含“平台概览”“参数配置与运行”“运行分析”“场景与决策”；连接后台后增加“项目中心”。快速调度模式保留“平台概览”“参数配置与运行”“运行分析”“绿电决策”。平台不再设置“工程架构”和“结果导出”业务页面。

## 本地演示

```bash
pip install -r requirements.txt
streamlit run app.py
```

此方式无需后台数据库，适合单人演示。项目版本、后台任务和历史结果需要启动接口服务与任务执行器：

```bash
uvicorn api:app --host 0.0.0.0 --port 8000
python worker.py --poll-seconds 2
```

前端设置`PLATFORM_API_URL=http://127.0.0.1:8000`后，“项目中心”会自动出现。当前数据库为 SQLite，适合单服务器试点；多实例生产部署应将仓储适配为 PostgreSQL，并把成果文件迁移到对象存储。

## 质量检查

```bash
pip install -r requirements-dev.txt
python -m compileall -q app.py src tests
ruff check .
python scripts/deployment_preflight.py --profile all
pytest
```

自动化质量门还会构建部署镜像。V17 的 S0、S4、S8 和默认快速调度均有黄金回归基线。

## 云端演示说明

Streamlit Community Cloud 只运行前端时，项目中心不会出现，其他 V17 配置、求解、分析、场景比较和成果下载仍可使用。不要把云端前端的后台地址配置为`127.0.0.1:8000`；若需要项目中心，应配置一个浏览器可访问的独立接口地址。

## 使用边界

本平台用于园区综合能源方案筛选、低碳指标评估和绿电方案比较。正式决策前必须以项目实测负荷、当地合同电价、设备报价、碳排放因子和工程边界重新标定。平台不替代配电网潮流、短路电流、继电保护、接入审查、施工图或财务尽调。
